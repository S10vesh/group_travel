# Система планирования путешествия группой

## Назначение
Консольное приложение для предварительного планирования совместных путешествий.  
Позволяет проверить базовые условия поездки (количество участников, бюджет, дату начала) и получить рекомендацию, можно ли начинать детальное планирование.

## Целевая аудитория
- Группы друзей и коллег, которые хотят организовать совместную поездку
- Студенты и молодёжные компании
- Небольшие туристические группы

## Предметная область
Планирование группового путешествия: формирование состава участников, оценка бюджета, выбор даты начала поездки и проверка возможности её организации.

## Основные сущности
- Путешествие (название, дата начала, бюджет)
- Участник группы
- Условия поездки (минимальное количество участников, минимальный бюджет)

## Основные функции
- Ввод основных параметров путешествия
- Проверка достаточности количества участников
- Проверка достаточности бюджета
- Проверка корректности даты начала
- Выдача итогового статуса возможности планирования

## План развития проекта
На следующих этапах планируется:
- работа с коллекциями участников и маршрутов;
- сохранение данных в файлы;
- реализация сущностей в виде классов;
- создание веб-приложения на Django;
- работа с базой данных и пользователями;
- разработка REST API;
- контейнеризация приложения.
