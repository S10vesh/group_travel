# Система планирования путешествия группой

## Назначение
Консольное приложение для планирования совместных путешествий.
Позволяет работать с путешествиями и участниками: добавлять, искать,
проверять готовность группы к планированию и сохранять данные между запусками.

## Целевая аудитория
- Группы друзей и коллег, которые хотят организовать совместную поездку
- Студенты и молодёжные компании
- Небольшие туристические группы

## Предметная область
Планирование группового путешествия: формирование состава участников,
оценка бюджета, выбор даты начала поездки и проверка возможности её организации.

## Основные сущности
- Путешествие (название, дата начала, бюджет, минимальное число участников)
- Участник группы
- Группа (путешествие + его участники)

## Основные функции
- просмотр и поиск путешествий;
- добавление новых путешествий;
- добавление участников к путешествию;
- проверка, достаточно ли участников;
- проверка готовности группы к планированию;
- сортировка путешествий по бюджету;
- сохранение данных в JSON.

## Основные классы

### Trip — путешествие
- **Атрибуты:** `id`, `name`, `start_date`, `budget`, `min_participants`
- **Методы:**
  - `is_budget_enough(min_budget)` — достаточен ли бюджет;
  - `can_start(current_count)` — хватает ли участников;
  - `__str__()` — строковое представление.

### Participant — участник
- **Атрибуты:** `id`, `name`, `trip` (объект `Trip`)
- **Методы:** `__str__()`

### TravelGroup — группа
- **Атрибуты:** `trip` (объект `Trip`), `participants` (список `Participant`)
- **Методы:**
  - `add_participant(participant)` — добавить участника;
  - `count()` — количество участников;
  - `is_ready()` — готова ли группа к планированию;
  - `__str__()` — строковое представление.

## Взаимодействие объектов
- `Participant.trip → Trip` — участник ссылается на своё путешествие.
- `TravelGroup.trip → Trip` — группа создаётся для путешествия.
- `TravelGroup.participants → [Participant, ...]` — группа хранит своих участников.
- В JSON сохраняются идентификаторы (`trip_id`), при загрузке восстанавливается ссылка на объект `Trip`.

## Хранение данных
Данные хранятся в JSON-файлах в каталоге `data/`:
- `data/trips.json` — путешествия;
- `data/participants.json` — участники.

При загрузке JSON-данные преобразуются в объекты `Trip` и `Participant`,
при сохранении объекты преобразуются обратно в словари.

## Структура проекта
- `main.py` — точка запуска и меню;
- `storage.py` — загрузка и сохранение JSON (с преобразованием в объекты);
- `utils.py` — безопасный ввод чисел и дат;
- `models/` — пакет моделей предметной области:
  - `models/__init__.py` — экспорт классов `Trip`, `Participant`, `TravelGroup`;
  - `models/trips.py` — класс `Trip` и функции работы с путешествиями;
  - `models/participants.py` — класс `Participant` и функции работы с участниками;
  - `models/groups.py` — класс `TravelGroup` (путешествие + участники);
- `data/` — файлы данных:
  - `data/trips.json` — данные о путешествиях;
  - `data/participants.json` — данные об участниках;
- `tests/` — автоматизированные тесты:
  - `tests/test_trips.py` — тесты для класса `Trip` и функций путешествий;
  - `tests/test_participants.py` — тесты для класса `Participant`;
  - `tests/test_groups.py` — тесты для класса `TravelGroup`.
