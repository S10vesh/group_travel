# Проверка требований ПР5–ПР6

Проверено по разделам 5, 7.2 и требованиям к отчётам двух предоставленных PDF.
Это аудит итогового состояния проекта, а не подтверждение прохождения курса.
Roomly в методичках — пример: помещения адаптированы к путешествиям,
связанные записи — к участникам; условный статус — к готовности группы.

## Источник данных

Данные не скопированы в HTML и не импортированы в отдельную базу.
`storage.load_trips()` читает `data/trips.json` и создаёт объекты `Trip`.
`storage.load_participants(trips)` читает `data/participants.json` и связывает
участников с путешествиями через `trip_id`. Представления вызывают загрузку
на каждом запросе. `TravelGroup.is_ready()` определяет статус группы.

При проверке в файлах находились:

| Поездка | Бюджет | Участники | Минимум |
| --- | --- | --- | --- |
| №1 «Крым 2026» | 45000 | Иван, Мария, sdf | 3 |
| №2 «Сочи выходные» | 28000 | Алексей | 4 |
| №3 с пустым названием | 234 | Нет | 342 |

Пустое название показывается как «Без названия» через фильтр `default`.
Исходные записи не исправлялись и не заменялись демонстрационными данными.
Тест с временными JSON подтверждает, что изменения файла видны уже при
следующем HTTP-запросе, без перезапуска и без изменения рабочих файлов.

## Что дополнительно проверено

- Реальные ответы локального сервера для главной, списков, всех текущих карточек.
- Соответствие имён и связей участников исходным JSON.
- HTTP 200 для собственных CSS, JS и SVG, корректные типы содержимого.
- HTTP 404 для неизвестных ID, адресов и нечисловых идентификаторов.
- Свой шаблон 404 при DEBUG=False; сообщения о конкретном отсутствующем
  объекте при обоих значениях DEBUG.
- Пустые коллекции, оба статуса группы, дата, экранирование HTML, кириллица.
- Зависимости: pip check.

Визуальная адаптивность в браузере и фактическое открытие диалога печати
автоматически не проверены: проверены CSS/JS, их подключение и HTTP-загрузка.
Это остаётся ручной проверкой перед защитой. Bootstrap подключён с CDN;
его загрузка внешним браузером в рамках аудита не подтверждена.
